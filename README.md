# SDN OpenFlow Network Monitoring System

## Status 
Ongoing project

## Description
A Software Defined Networking project using Ryu controller and OpenFlow protocol for programmable network control and monitoring.

## Technologies
- Python
- Ryu Controller
- OpenFlow 1.3
- Mininet
- Ubuntu Linux

## Files

controller.py - Ryu SDN controller implementation
topo.py - Mininet network topology
